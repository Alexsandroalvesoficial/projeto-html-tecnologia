# Projeto HTML - Tecnologia e Desenvolvimento Web

Projeto criado como desafio prático da trilha de HTML da DIO.

## Objetivo
Construir uma página web básica e praticar as tags HTML estudadas nas aulas.

## Tags utilizadas
- Títulos: `h1` até `h6`
- Texto e formatação: `p`, `mark`, `small`, `i`, `u`, `strong`, `del`
- Listas: `ol`, `ul`, `li`
- Link e separação: `a`, `hr`
- Outros elementos: `sub`, `sup`, `blockquote`, `abbr`, `font`

## Como visualizar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

## Observação
A tag `font` foi incluída porque faz parte dos requisitos do desafio, mas é obsoleta
no HTML moderno. Em projetos atuais, use CSS para controlar cor, tamanho e família
tipográfica.
